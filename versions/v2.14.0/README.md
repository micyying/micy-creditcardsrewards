## 解析修正

- 重建 PDF 文字時忽略不可見空白的寬度，避免交易編號黏住金額；保留同一個字詞的字體分片。
- BOC：交易日和記賬日分開，保存 ##；Go 白金／鑽石分開，HKD／CNY 分賬。費用、零數、還款、積分抵扣與現金回贈分開。Gift Points 調整不冒充本期賺取。
- 國泰：正確關聯商戶和交易編號，提取結單實際里數。結單只有一個日期時，不虛構第二日期；銀行綜合結單不當作信用卡結單。
- AEON：依卡標題拆分戶口，處理折行商戶和帶逗號積分；分別保存 earned／redeemed／balance／expiring。WAKU COIN REBATE／REDEMPTION 是兌換，不能重計新回贈。
- Mox：銀行 CashBack、迎新、轉賬及信用卡消費分開；保存 activity／settlement 日期。正數未必是還款，未有證據的入賬保留待核實。外幣港幣入賬額不重加費用。
- 匯入以結單內容及原始行識別重複，保留同日同額同商戶的真實重複交易。停用原版可能誤刪交易的啟動去重。
- 確認入賬後可在「結單賬本」查看原始帳項和獎賞單位。修改候選分類或金額不覆蓋原始提取。儲存失敗會保留確認頁。

## 規則界線

AEON Purple 按使用者指定每分 HK$0.004 估值，WAKU COIN 每 coin HK$1；估值與現金分欄。國泰里數保留原單位，不預設現金估值。

歷史消費不自動套用現行推廣。新匯入消費的應得回贈保持待核實：Mox 首期 2% 的起止日期、歷史優惠登記資格、商戶 MCC、國泰完整取整機制等，不能從實收總額倒推成確定規則。原來的手動記錄、卡片管理與推薦介面保留。

現金回贈有明示月份時使用該月份，否則按入賬月顯示並標記消費月份未明。賬面吻合不代表銀行已給足應得回贈。缺少 Mox 銀行結單時，不把未知實收填零。
