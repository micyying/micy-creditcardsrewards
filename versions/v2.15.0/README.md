# v2.15.0 — Chill 逐筆理論回贈

依使用者「Micy刷哪張 規則／Chill卡回赠分析」v2 模型補上預測引擎。預測與原始月結單、實際回贈分開儲存。

- 一般合資格消費估算 HK$1=1 Gift Point；250分約HK$1。
- 網上／海外：基本積分 + 4.6%額外現金；Chill商戶達同曆月實體零售HK$1,500後：基本積分 + 9.6%額外現金。
- 額外現金共用每曆月HK$150上限，依交易日期及順序分配；月結分欄仍跟月結單，不用分欄月份決定回贈門檻。
- 電子錢包、增值及繳費依模型排除；超過7日才誌賬的交易不估額外現金。
- 不使用 `##` 作為優惠資格。商戶名称／渠道分類是估計；每筆可改成網上、實體、Chill或不合資格。
- 保留理論現金小數與整元情境值；不調整理論去湊銀行實際回贈。
- 已匯入紀錄在載入、同步、修改和新匯入後補算，無須重新匯入PDF。
- 修正入口一直引用v2.14.1解析器的打包錯誤；根目錄與獨立版本均驗證各自腳本存在。

## 規則來源及估計限制

使用者指定的對話規則，並核對以下中銀公開資料（2026-09-05）：

- https://www.bochk.com/dam/boccreditcard/chillcard/chill_offer_tnc_tc.pdf
- https://www.bochk.com/dam/boccreditcard/chillcard/chilll_merchant_banner_tc.jpg

商戶表是有日期的2026快照，新標商戶自2026-05-01使用。2026以前及推廣到期以後仍給出數值，明確標為沿用v2規則的歷史／未來情境估計，非已驗證的當期銀行資格。商戶名稱不是MCC；未知渠道暫按實體零售估計，使用者可修改。僅以已匯入交易計算門檻和上限；补入相鄰月結單後會重算。同一月結單可跨兩個曆月，因此分欄的現金合計可能高於单个曆月HK$150。

零售金額取整估算積分，逐筆約值顯示至港幣分。額外現金上限採交易順序分配，累積四捨五入差額分攤以保持逐筆與上限一致。銀行實際現金仍獨立按Cash Rebate描述中的月份歸屬。

退款尚未自動關聯原消費；遇到已退款交易可把原消費預測分類改為不合資格。這些假設不改寫原單或銀行已入賬值。
