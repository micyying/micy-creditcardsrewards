# v2.16.1 — 分類、Mox 還款及月結分欄修正

在原 app 上修正使用者回報的五項問題，保留 v2.16.0。Mox／Chill 回贈率引擎不變。

- Circle K 所有卡片一律分類為「其他」，不再是汽油或超市。修正預設關鍵字、既有紀錄、匯入候選和已學習分類，保留完整商戶字串及 ##。
- RentSmart／Rent Smart 獨立為「RentSmart 繳租」分類。平台專屬回贈規則標為 PENDING，不新增未提供的優惠規則。
- Mox 信用卡正數只有在明示還款或與結單戶主姓名相符時才判為還款，名稱先按字詞正規化。真正商戶退款仍保留退款；不把所有正數硬改為還款。舊結單可從標準原始檔名補回戶主欄位。
- Mox 銀行轉入與轉出依原單方向分開。銀行扣款與信用卡還款同卡、同結算日、同金額且雙向唯一時關聯，顯示兩邊帳項為同一筆還款；不刪原始行、不改金額或來源 ID。
- 回贈／其他帳項分成兩個板塊。回贈依序列現金、積分、里程、兌換及迎新，標頭合計為現金＋里程約值＋兌換＋迎新；積分另列避免與兌換重複計算。還款、轉賬、退款、零數及費用放在其他帳項。迎新亦加入實際回贈總額及彈窗，Mox 消費 CashBack 對帳仍獨立。
- Mox 信用卡分欄採結單結束月份：例如 2月10日至3月9日的3月結單，歸3月。原交易日、結算日及周期不改；現金回贈對帳繼續按結算曆月。

已導入資料在載入及重算時自動遷移，無須重新導入月結單。重複遷移不會重複建立分類或帳項。
