# v2.18.0 — Go人民幣消費與倍數積分

沿用原 app、儲存格式及原網址，保留 v2.17.0。

- 消費明細同時顯示HKD及CNY購物；外幣原始記錄仍保存於原帳本，不複製交易。HK$與CN¥分列，結單摘要分幣種替換明細小計；卡片／分類篩選同步套用。外幣消費移出其他帳項，退款／還款仍保留。
- 記錄頁預測及預測彈窗包括人民幣購物。CNY明細可直接設定Go地區、付款渠道及商戶資格，不使用HKD金額編輯器。Go以人民幣1元=港幣1元的獎賞基準計算，並非兌換匯率。
- 2026-07-01至09-30已登記手機推廣：白金內地10X／香港5X，鑽石內地20X／香港10X；以250分=HK$1顯示名義4%／2%／8%／4%。由成功登記曆月生效，含日常手機優惠的額外積分每曆月共用25,000分上限，基本1X另計。港幣與人民幣、內地與本地共同套用上限。
- 登記不明時保留現有資格預測及條件成立情境，兩者各自完整套用月度上限。CNY只提供地區候選，##不決定任何優惠資格。已知非手機或Alipay／WeChat渠道不套用指定手機優惠。
- 指定Go商戶5%優先於額外倍數推廣，拆分0.4%積分與4.6%現金；不疊加。名單、日期、渠道及高鐵／滴滴／京東／指定超市附加條件保留。現金／積分各自上限，不將5%全寫成特別積分。
- GP Rebate通知保留為原始證據；如已包含在月結積分淨調整中，不重複加入實際積分。舊自動匯入資料可自動去重，手動記錄保留；淨調整明示不是本期總賺取。
- 規則追蹤文字同步改為每週一上午9點。私人追蹤基準不發布。
