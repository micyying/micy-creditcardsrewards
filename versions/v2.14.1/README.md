# Micy刷哪張 v2.14.1

- 「消費紀錄」按月結周期的起始月份分欄。例：2026-07-19 至 2026-08-14 的 Chill 周期，全部放在 2026 年 7 月。
- 每筆仍顯示月結單中的真實交易日期，不改成月份第一日。
- 商戶名稱直接保存及顯示月結單原文，包括 `##`；另設 `merchant_name_normalized` 供內部分類，不取代畫面名稱。
- 已由 v2.14.0 匯入的帳項會在載入時補上周期月份並恢復原始商戶名稱，無需重匯。
- 手動新增及沒有月結來源的舊紀錄仍按交易日期的自然月份顯示。

v2.14.0 保留於 `/versions/v2.14.0/`。
