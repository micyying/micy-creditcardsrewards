# v2.16.0 — Mox 現金回贈預測與對帳

直接擴充現有 Trae app。Chill v2.15.1 引擎保持不變，Mox 使用獨立模組；舊版保留於 `/versions/v2.15.1/`。

## 已接入規則

依「Micy刷哪張 規則／Mox卡回赠分析」最後更正：首期普通合資格消費 2%，之後普通 1%、超市 3%。首期全部 3% 的舊說法已撤回。

- 歷史資料顯示 4 月 11 日消費仍符合 2%、4 月 13 日消費符合 1%。2026-02-10 至 04-11 僅為首期 2% 情境範圍，非確認迎新起止日；04-12 邊界不確定。用戶可設定確認日期，不把三個月換算成 90 天。
- 2026-04-13 至 08-31 普通 1% 為歷史情境推斷；超市名稱只是 3% 候選。MCC／用戶指定分類優先，便利店不自動算超市。首期超市 2%／3% 仍待核實。
- 2026-09-01 起普通交易按 Mox+ 資格分 1%／2%；超市 3%，不相加。用戶於 2026-09-06 確認沒有 Mox+，新增帳本設定預設為「沒有」。可在 app 設定 Mox+ 有效期。
- 現金計劃不套用里數計劃的外幣費用優惠；直接以原單港幣金額計算，不重複增加 1.95% 手續費。逐筆四捨五入至分屬預測假設。
- 不使用 Chill 的 HK$1,500 門檻或 HK$150 上限，亦不以 ## 判斷資格。
- 費用、還款、退款、轉賬、銀行戶口賬項及迎新不計消費回贈。歷史八達通／電子錢包／政府繳費／租金等保留資格疑問及情境範圍，不用實收金額倒推規則。租金按一般比率列情境，其餘未核實繳費／增值以 0 作顯示情境並列可能值；可按實際資格手動修改。

## 預測與證據

`expected_cashback` 在资格／日期未知時保持 null，但介面仍顯示 `scenario_cashback` 及上下界，避免把未知當成銀行欠付。`expectedReward` 為介面情境約值。已知候選資格仍標記 INFERRED。

信用卡消費分欄保留月結周期；對帳按 settlement_date 的曆月與銀行 CashBack 入賬月比較。activity_date、settlement_date、statement_period、完整商戶及外幣資料均保留。已匯入資料自動補算。

同日多筆合計及延遲 1–3 日相同金額只列候選配對，候選可重疊、不會消耗或分攤銀行證據。`allocated_actual_cashback` 始終為 null。同月相同總額但有不確定資格仍為 UNRESOLVED；全部候選預測相同且無缺日期時為 MATCHED_AGGREGATE，並非逐筆確認。缺銀行結單為 INSUFFICIENT_DATA，實收保持 null，介面顯示「未取得」。

迎新獎賞獨立列出，不混入 CashBack。`mox-reconciliation` 彈窗提供月份對帳、日期候選、迎新及規則設定。推薦「刷哪張」也使用同一 Mox 引擎，不再疊加舊規則。
